Student Management Demo

A simple demo project created for EL 13 to practice commit messages and project organization using GitHub.

Project Structure

├── src/

├── tests/

├── docs/

Folder Description

* src/ – Contains the main application code.
* tests/ – Contains basic testing scripts.
* docs/ – Contains project documentation.
* assets/ – Stores images and other visual resources.

Features

* Simple Python program.
* Basic test example.
* Organized folder structure.
* Markdown documentation.

Expected Output

Welcome to Student Management Demo!

Purpose

This project demonstrates how to organize files and record changes using descriptive Git commit messages.
